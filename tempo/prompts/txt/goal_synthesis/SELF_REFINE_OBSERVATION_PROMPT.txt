## Standard quality checks
1. **Redundancy**: Are any goals too similar and should be merged?
2. **Overly broad**: Is any goal so broad it's meaningless? (e.g., "is trying to be productive")
3. **Restating an observation**: Is any goal just describing a single screen moment? Apply the completability test. Common failure: "is editing a spreadsheet" (observation) instead of the underlying striving it serves.
4. **Too surface-level**: Is any goal just a task category? Push past "browses the web" toward the underlying pursuit.
5. **Too few goals**: If the synthesis produced fewer than 5 goals, consider whether you have: (a) lumped distinct strivings into one overly broad goal that should be split, (b) missed entire life domains (e.g., only work goals, no personal/social/health strivings), (c) overlooked avoidance or obligation patterns that constitute separate pursuits. But do NOT force goals that aren't supported by behavioral evidence — 3 well-grounded goals are better than 8 thin ones.
6. **Evidence quality**: Does the evidence actually support each goal? Remember: screen presence ≠ engagement.
7. **Language clarity**: Is any goal written in academic jargon? Rewrite to sound like something a thoughtful friend would say.

## Phrasing checks
8. **Phrasing variety**: Do multiple goals use the exact same construction (e.g., all start with "is trying to...")? Vary naturally: "is pursuing," "is invested in," "is working to," "is drawn to," "is building," "is growing into," "is dedicated to," "is actively avoiding," etc.
9. **Wish vs. pursuit**: Does any goal read as a desire rather than an active pursuit? "Wants to," "hopes to," "wishes to" describe aspirations, not strivings. If there's behavioral evidence, rephrase as what {user_name} is actively doing.
10. **Behavioral grounding**: Since these are inferred from raw screen observations (not self-report), does each goal describe something the system has evidence of {user_name} *doing*, not just intending?

## Theory-grounded checks
11. **Conflict completeness** (Emmons): Are all key tensions between goals captured in goal_relations?
12. **Avoidance & ambivalence gap** (Markus & Nurius): Are ALL goals pure approach? Check:
   (a) If no avoidance goals: look for procrastination, consistent avoidance, or defensive behaviors.
   (b) If no `mixed` goals: look for goals where {user_name} is attracted to an outcome but also fears aspects of it. For `mixed` goals, BOTH `identity_link` and `feared_self` must be populated.
13. **Ideal/ought balance** (Higgins): Is everything aspirational? Look for obligation-driven patterns: deadlines, external expectations, "should" behaviors.
14. **Autonomy signal check** (SDT): Are all goals autonomous? Look for grudging patterns: reactive behaviors, externally-triggered actions, low-engagement tasks.
15. **Level appropriateness** (Emmons): Is each goal at the right abstraction level? Not so abstract it's a need label ("wants competence"), not so concrete it's restating an observation ("editing a spreadsheet"). Apply the completability test.
16. **Synthesis quality**: Does each `synthesis_evidence` convincingly explain WHY diverse observations belong under one striving? If tautological ("these all involve a browser"), it's a surface grouping, not a striving.
17. **Need tag accuracy**: Did need tags drive the goal text? If it reads like a need description ("is seeking competence and mastery"), rewrite as what {user_name} is actually doing.
18. **Constraint compliance**: Are [locked] goals preserved? Are [user-edited] labels kept verbatim? Are user annotations reflected? NEVER merge or remove a [locked] goal.

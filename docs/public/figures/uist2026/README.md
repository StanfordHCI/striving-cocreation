# UIST 2026 paper figures

Original, unmodified PNGs from the camera-ready ACM TAPS source package,
`uist26-156-TAPS/source/figures`, supplied in Downloads. All five files are
byte-for-byte identical to the figures in the [arXiv v2 source](https://arxiv.org/src/2605.00497v2),
submitted September 9, 2026. Verified September 21, 2026.

Paper: Sapkota et al., “What Are You Really Trying to Do?”: Co-Creating Life
Goals from Everyday Computer Use. UIST 2026.
[DOI: 10.1145/3830398.3830630](https://doi.org/10.1145/3830398.3830630).
See the repository's `LICENSE-CONTENT.md` for CC BY 4.0 licensing.

- Figure 2: `architecture.png`.
- Figure 3: `editing.png`.
- Figure 4: `striving-quality.png` above `striving-representativeness.png`,
  preserving the two-panel arrangement in the paper.
- Figure 5: `editing-results.png`.

The homepage references these assets, rather than older results plots in the
parent directory. Captions on the website are concise summaries, not verbatim
paper captions. No figures have been redrawn or recolored.
